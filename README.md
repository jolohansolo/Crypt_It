## Project goals

CryptoLab is a command-line application for experimenting with
classical and modern cryptographic algorithms.

- Caesar cipher
- Vigenère cipher
- substitution ciphers
- hashing
- encoding/decoding
- cryptographic utilities
- CLI interface
- automated tests
